# Заметки для разработчика / агента

Статический сайт (`frontend/`), без сборки и зависимостей. Превью Shogo
отдаёт `frontend/` как есть (`shogo.preview.json`).

* Порядок скриптов важен: `plc-lib → plc-prod → plc → plant → plant-flow → db → render → ui`.
  `tests/load.js` повторяет его для Node.
* Логику ПЛК меняйте в `plc*.js`, сверяясь с `docs/plc/<POU>.txt`. Если в
  тексте POU условие иное — исправляйте эмуляцию, а не подгоняйте модель.
* Физику (производительности `Q`, датчики, токи) — в `plant*.js`. Узкое
  место тракта проявляется как авария ДП (подпор) у элемента перед ним.
* Датчики положения (ДКС, концевики, метка стола) отражают положение вала
  всегда, а не только при работе привода — иначе ПЛК видит ложные фронты.
* Проверка: `node tests/run.js` (≈1 мин), затем браузер — консоль без ошибок.
* Хранилище браузера: `bugry-sim-v1` (уставки, наработка), `bugry-db-v1` (рецепты, ПП).
